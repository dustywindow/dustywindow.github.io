# 안산동산고등학교 과학실 사용 신청

GitHub Pages로 배포되는 과학실(화학·생명과학·물리·지구과학 실험실) 사용 신청 웹앱입니다.

## 페이지 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 첫 페이지: **과학실 사용 신청** / **과학실 사용 현황 확인** 버튼 |
| `apply.html` | 신청서 작성: 실험실, 날짜, 시간(복수 선택), 사용 목적, 실험 계획, 지도 선생님 |
| `status.html` | 날짜별 시간표(시간 × 실험실)로 신청 현황과 상태(신청 · 확인보류 · 승인) 표시 |
| `admin.html` | 담당자 페이지: 신청서 확인, 상태 변경, 메모 작성, 삭제 |

- 이미 **승인**된 실험실·시간은 신청 화면에서 선택할 수 없고, 담당자도 겹치는 신청을 중복 승인할 수 없습니다.
- 현황표의 빈 칸을 누르면 해당 실험실·날짜·시간이 채워진 신청서로 이동합니다.

## 설정 (`js/config.js`)

- `labs`, `periods`: 실험실 목록과 신청 시간 목록
- `adminPassword`: 담당자 페이지 비밀번호 (기본값 `dongsan2026`, 반드시 변경하세요)
- `firebase`: 데이터 저장소 설정

### 저장소에 대하여

`firebase`가 `null`이면 신청 내용이 **각 브라우저의 localStorage에만** 저장됩니다(테스트 모드).
이 경우 학생이 낸 신청을 담당자가 다른 기기에서 볼 수 없으므로, 실제로 쓰려면 Firebase를 연결하세요.

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 만들고 **Firestore Database**를 생성합니다.
2. 프로젝트 설정 → 웹 앱 추가 → 표시되는 설정값을 `js/config.js`의 `firebase`에 붙여 넣습니다.
3. Firestore 보안 규칙을 설정합니다. 신청서는 `reservations` 컬렉션에 저장됩니다.

> 담당자 비밀번호는 브라우저에서 확인하는 방식이라 소스 코드를 보면 알 수 있습니다.
> 학교 내부용 간단한 운영에는 충분하지만, 보안이 중요하다면 Firebase Authentication으로
> 담당자 로그인을 만들고 Firestore 규칙에서 상태 변경·삭제를 담당자에게만 허용하세요.
